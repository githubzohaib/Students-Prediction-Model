# 🎓 Student Score Prediction Model

A Machine Learning web application that predicts a student's score based on study hours, attendance, and class participation. The model is trained using supervised learning on a dataset of 1 million student records and is deployed with a React frontend and FastAPI backend.

## 🚀 Live Demo

🔗 Live Project: https://students-prediction-model.vercel.app

---

## 📌 Features

- Predicts student scores using a trained Machine Learning model.
- User-friendly React interface.
- FastAPI backend for handling prediction requests.
- REST API integration between frontend and backend.
- Deployed frontend on Vercel.
- Deployed backend on Render.
